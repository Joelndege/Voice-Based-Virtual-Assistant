A lightweight voice assistant built with browser technologies for the Comprehension 2 project.

01

Project overview

The Voice-Based Virtual Assistant is a functional browser prototype. It accepts spoken or typed commands, recognises a set of useful intents, and returns a response as text and optional speech.

02

Objectives

  • Build a simple interface for voice commands.
  • Perform practical operations such as calculations, searches, weather lookups, timers, notes, and FAQs.
  • Provide visible feedback and spoken responses.
  • Keep the experience usable when voice input is unavailable.
03

How it works

The page uses the browser’s Web Speech API. Speech recognition converts microphone input into text; an intent handler maps that text to an operation. Speech synthesis reads the response aloud when supported. Saved notes and to-do items use local browser storage.

Microphone→Recognition→Intent→Response
04

Commands supported

time / dateReturns the local time or today’s date.
joke / helpShares one of several random jokes or lists capabilities.
calculate …Solves arithmetic using words or symbols, for example “25 times 8”.
weather in …Looks up current conditions for a city.
search for …Creates a link to web search results.
open YouTubeOpens selected websites in a new browser tab.
set a timer …Creates a timer or reminder.
add a note …Saves notes and to-do items in this browser.
project questionAnswers basic questions about the assignment.
05

Tools and limitations

Built with HTML, CSS, and JavaScript. Voice input depends on browser support and usually requires HTTPS, such as GitHub Pages. Weather requires an internet connection and uses Open-Meteo. Notes and tasks stay in browser storage. Timers run in the page and can use notifications if permission is already granted. A webpage cannot launch native desktop applications, and responses are limited to the implemented commands.
